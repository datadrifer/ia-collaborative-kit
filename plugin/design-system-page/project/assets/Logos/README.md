# Logos

IA Collaborative's mark, from IA's own site files. Each file has its ink baked in: use the file whose ink suits the ground, never recolour one.

| File | Ink | Use it on |
| --- | --- | --- |
| `ia-logo.svg` | Black #000000 | White (`background`) and IA's grey panel (`card`). The nav, a deck's title and closing slides, the one-pager footer. |
| `ia-logo-white.svg` | White #ffffff | IA blue (`brand-strong`), black (`inverse-surface`) and dark photography. |
| `ia-monogram.svg` | Black #000000 | Light grounds, where the lockup does not fit or the name is already said: avatars, a slide's corner, a favicon. |
| `ia-monogram-white.svg` | White #ffffff | IA blue, black and photography. |

- The IA letters are cut out of the circle, so the ground shows through them.
- Lockup at least 24px tall on screen; monogram at least 16px.
- Clear space: the monogram's height on every side.
- Never recolour (not even IA blue), stretch, outline, rotate or retype the mark. Never set "IA Collaborative" in another face beside it.
- The white versions and the monogram were made from IA's own black logo by changing the ink or keeping the circle alone; nothing was redrawn.
