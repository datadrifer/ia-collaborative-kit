# Avatar

A person, or IA itself, as a photo, a mark or initials.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- IA speaks as the monogram (ia-monogram) in conversational panels; people get their photo or initials.
- Never a stock face.

## Parts

Build a Avatar from its parts; each is exported on its own (`IACollaborative.AvatarImage`).

- **AvatarImage**: The photo or mark.
- **AvatarFallback**: Initials when there is no image.
- **AvatarGroup**: A row of overlapping avatars.
- **AvatarGroupCount**: The "+3" at the end of a group.
- **AvatarBadge**: A small status dot.
