# Command

Search and jump: a filterable list of insights, services and pages.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- Group results by kind; the first match is selected.

## Parts

Build a Command from its parts; each is exported on its own (`IACollaborative.CommandInput`).

- **CommandInput**: The search field.
- **CommandList**: The results.
- **CommandEmpty**: Shown when nothing matches.
- **CommandGroup**: A group of results.
- **CommandItem**: One result.
- **CommandSeparator**: A hairline between groups.
- **CommandShortcut**: A keyboard hint.
- **CommandDialog**: The same list in a Dialog.
