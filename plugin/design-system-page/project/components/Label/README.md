# Label

The visible name of a field, tied to it by htmlFor so a click focuses the field.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- IA's form labels are the micro step in uppercase and ink-eyebrow grey: Label className="text-micro uppercase text-ink-eyebrow".
- Every Input, Textarea, Select, Checkbox, Switch and RadioGroup item has one.
