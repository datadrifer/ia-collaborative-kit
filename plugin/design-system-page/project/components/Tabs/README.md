# Tabs

Switches between views of the same thing, like the site's Classic, Agentic and Machine modes.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- Two to five tabs; the active tab is the only one in full ink.

## Parts

Build a Tabs from its parts; each is exported on its own (`IACollaborative.TabsList`).

- **TabsList**: The row of triggers.
- **TabsTrigger**: One tab.
- **TabsContent**: The panel a tab shows.
