# RadioGroup

One choice from a short list.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- Two to five options; more becomes a Select.

## Parts

Build a RadioGroup from its parts; each is exported on its own (`IACollaborative.RadioGroupItem`).

- **RadioGroupItem**: One option, always beside its Label.
