# Toaster

A short confirmation that something happened (Sonner).

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- Put one Toaster in the app shell; call toast() with a sentence that says what happened.

## Parts

Build a Toaster from its parts; each is exported on its own (`IACollaborative.toast`).

- **toast**: The function that shows a message: toast("Message sent").
