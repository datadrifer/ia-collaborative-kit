# Table

Rows of facts: a framework, a comparison, results.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- A caption says what the table holds. Head in medium weight; numbers right-aligned in tabular figures.

## Parts

Build a Table from its parts; each is exported on its own (`IACollaborative.TableCaption`).

- **TableCaption**: What the table holds.
- **TableHeader**: The row of column names.
- **TableHead**: One column name.
- **TableBody**: The rows.
- **TableRow**: One record.
- **TableCell**: One value.
- **TableFooter**: A totals row.
