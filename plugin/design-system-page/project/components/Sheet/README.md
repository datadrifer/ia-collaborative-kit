# Sheet

A panel from the edge of the screen: IA's site menu opens this way.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- Use for navigation and filters, not for a step that needs an answer (that is a Dialog).

## Parts

Build a Sheet from its parts; each is exported on its own (`IACollaborative.SheetTrigger`).

- **SheetTrigger**: The control that opens it.
- **SheetContent**: The panel.
- **SheetHeader**: Its title and description.
- **SheetTitle**: The name.
- **SheetDescription**: One line under it.
- **SheetFooter**: Its actions.
- **SheetClose**: Closes it.
