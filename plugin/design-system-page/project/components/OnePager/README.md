# One-pager

IA's one-page thought-leadership layout for US letter (816 × 1056 px): a photo-led hero band, the marked statement beside a short lead, the content as a three-column grid of hairline cells, and a foot with the logo and the action as a line.

This is a page template, not a code component: it shows the layout the README's **One-pagers and print** table specifies zone by zone. Make every one-pager this way, with the subject's own title, photograph, statement and parts.

- **Hero band:** 408px, full bleed; one of IA's photographs under the black scrim; `ia-logo-white` top-left; the Title Case title (44px, 600, white) bottom-left over a 1px white rule and a one-line dek.
- **Intro row:** the typed bold blue `*` and a 26px medium statement on the left; a 14px lead in #525252 on the right.
- **Content grid:** three columns; each cell a hairline, the name in IA blue with its initial in 600, a 14px question in 600, one 13px sentence in #525252.
- **Foot:** a hairline, `ia-logo` left, "Let's talk." in IA blue and the contact address right.
- On paper there is no button, no grey panel and no lettering masthead.
