# Tooltip

A few words on hover or focus.

This is the shadcn/ui component Substrate installed in IA's code projects (Radix underneath), sized from IA's tokens: the same code an agent uses in a project.

- Never the only place an instruction lives.

## Parts

Build a Tooltip from its parts; each is exported on its own (`IACollaborative.TooltipTrigger`).

- **TooltipTrigger**: The control the hint belongs to.
- **TooltipContent**: The hint.
