The IDEALS Model for Custom AI Implementation

Six questions we answer before we build an AI tool.

*Answer the questions, then build the tool.

Every custom AI tool is different, but each one rests on the same six components. Human-Centered Workflow Analysis, the process we use to design them, starts with the question each component raises.

Intelligence

What model, algorithm + context will we engineer?

Usually a mix of models, each with a job. Choose for the task, not for comfort.

Data

What data sources + integrations will unlock value?

Proprietary data is the edge. Govern it, and retrieve only what the task needs.

Experience

How will it be used?

The interface is the system. Design for the decisions people need to make.

Autonomy

How independently capable is it?

Map where a person guides and signs off, and where the tool acts alone.

Learning

How will it learn + improve?

Build evaluation in from the start, and review it for drift.

Security

How will it ensure privacy, compliance + trust?

Red-team it during planning. Security designed in beats security bolted on.
